# סידור בית אהרן וישראל — PWA (ספר מודפס)

אפליקציית ווב (Progressive Web App) שמציגה את **דפי הסידור המודפס** של  
**סידור בית אהרן וישראל** (סטולין · קרלין) כמחליף־עמודים בסגנון ספר.

התוכן הוא סריקות PDF — **לא** נוסח שהומצא ולא הקורא הישן מבוסס־JAR.

## מקור ה־PDF

- קובץ: `SiddurBAV.pdf` (315 עמודים)
- מקור ציבורי: <https://stolin.info/stolin/SiddurBAV.pdf>
- בעותק האפליקציה: `docs/siddur.pdf` (וגם `siddur.pdf` בשורש)
- **לשימוש אישי** בתוכן שסופק מכתובת ציבורית זו.

## מיפוי עמודים

מספר עמוד עברי מודפס `H` ≈ אינדקס PDF (1-based) לפי:

```text
hebToPdf(h) = clamp(h - 1, 1, 315)
pdfToHeb(p) = clamp(p + 1, 1, 315)
```

דוגמאות מאומתות מהסריקה: ד(4)→PDF 3 · ו(6)→PDF 5 · כא(21)→PDF 20.  
PDF עמוד 2 = תוכן ומפתח.

## הפעלה מקומית

```bash
cd sidur-web/docs    # או sidur-web אם מגישים מהשורש
python3 -m http.server 3000
# או: npx --yes serve -l 3000
```

פתחו: `http://localhost:3000`

> חובה לשרת דרך HTTP (לא `file://`) — אחרת fetch / PDF.js / service worker לא יעבדו.

## UX

מסך הבית הוא **היום** — מה שצריך עכשיו, בלי חיפוש ובלי גלילה.

1. **תאריך עברי** + יום בשבוע, פרשת השבוע, ותגיות ליום (ראש חודש, חנוכה, צום…)
2. **עכשיו** — כרטיס אחד גדול לתפילה הנוכחית (שחרית / מנחה / ערבית / ק״ש שעל המטה),
   נקבע לפי זמני היום האמיתיים במיקום שלך. שאר התפילות בשורת צ׳יפים מתחת.
3. **היום** — מה שמיוחד לתאריך: הלל, מוסף לראש חודש, נר חנוכה (עם מספר הנרות),
   ספירת העומר (עם הספירה), סליחות, קריאת התורה לשני וחמישי, מגילה, ועוד.
   כל שורה קופצת ישר לעמוד בסידור.
4. **בתפילה** — תזכורות: יעלה ויבוא, על הניסים, עננו, משיב הרוח / מוריד הטל,
   ותן טל ומטר / ותן ברכה, אין תחנון.
5. **כל התוכן** — מפתח מלא עם חיפוש וסינון, בגיליון נפרד (לא על מסך הבית)
6. **קורא** — עמוד מודפס אחד בכל פעם (PDF.js), RTL, עם כותרת רצה ומעבר לעמוד

### תאריך וזמנים

התאריך העברי מתחלף **בשקיעה**, ולכן המיקום חשוב. בפתיחה הראשונה מתבקשת
הרשאת מיקום; אם היא נדחית אפשר לבחור עיר ידנית (ברירת מחדל לפי אזור הזמן).

### שבת ויום טוב

הסידור הוא **לימות החול** — אין בו תפילות שבת או חג. בשבת וביום טוב המסך
מציג הודעה קצרה במקום התפילות.

> התזכורות ההלכתיות הן לפי המנהג הנפוץ. מנהגים משתנים — ראו
> «מנהגים מרבותינו הקדושים מסטולין קרלין» בסידור (עמוד ש״ה).

## טכנולוגיה

- PDF.js 3.11 (jsDelivr / mozilla) + worker  
- HTML/CSS/JS ונילה, mobile-first לאייפון
- [@hebcal/core](https://github.com/hebcal/hebcal-es6) 6.9.2 — לוח עברי וזמני היום
  (מקומי ב־`js/vendor/hebcal.min.js`, כדי שיעבוד גם אופליין)

## הערות

- הסיבובים המעורבים ב־PDF (`/Rotate` 0/180/270) מטופלים ע״י PDF.js ב־`getViewport`.  
- תפריט הטקסט הישן מה־JAR הוסר — התוכן הוא דפי הספר בלבד.
