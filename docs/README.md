# סידור בית אהרן וישראל — PWA

אפליקציית ווב מתקדמת (Progressive Web App) של **סידור בית אהרן וישראל**, מומרת מסידור Java ME (MIDlet) המקורי.

נוסח התפילה לקוח מקבצי המשאבים שב־JAR (קידוד Windows-1255 / CP1255), ללא המצאת נוסח.  
סדר התפריטים והדפים תואם את המחלקות `Manager`, `MainMenu`, `FirstMenu` ו־`Page`.

## הפעלה מקומית

```bash
cd sidur-web
npx --yes serve -l 3000
# או:
python3 -m http.server 3000
```

פתחו בדפדפן: `http://localhost:3000`

> חובה לשרת דרך HTTP (לא `file://`) — אחרת ה־fetch וה־service worker לא יעבדו.

## התקנה ב־iPhone (הוספה למסך הבית)

1. פתחו את האתר ב־**Safari**
2. לחצו **Share** (שיתוף) → **Add to Home Screen** (הוסף למסך הבית)
3. לאחר הטעינה הראשונה האפליקציה זמינה גם במצב לא מקוון

## מבנה

```
sidur-web/
  index.html              # מעטפת האפליקציה (RTL, מובייל)
  css/app.css             # עיצוב mobile-first + safe-area
  js/app.js               # ניווט, קורא, העדפות
  js/zmanim.js            # חישוב זמנים (קירוב NOAA)
  sw.js                   # service worker (קאש לא מקוון)
  manifest.webmanifest    # מניפסט PWA
  icons/                  # אייקונים מה-JAR (book.png)
  data/
    menus.json            # תפריט ראשי + בחירת תפילה
    cities.json           # 120 ערים מקואורדינטות ה-MIDlet
    texts.json            # כל משאבי הטקסט (UTF-8)
    pages/*.json          # דפי תפילה מורחבים (כולל includes)
  scripts/convert_texts.py
```

## זמנים — הערות קירוב

החישוב מבוסס על משוואות שמש בסגנון NOAA (בדומה ל־`moladlib.SunRiseSet` ב-JAR):

- הנץ / שקיעה: זנית 90.833°
- עלות / מישיכיר / צאת: מעלות קבועות (≈16.1° / 10.2° / 8.5°)
- סו״ז ק״ש ותפילה: גר״א (שעות זמניות מהנץ עד שקיעה)
- הדלקת נרות: שקיעה פחות דקות העיר מה-JAR
- **אין** התחשבות מלאה בגובה / מנהג מקום / לוח עברי דינמי לתנאי תפילה

**לא להלכה למעשה.**

## המרת תוכן מחדש

```bash
# דורש את תוכן ה-JAR ב-/workspace/siddur-jar-inspect
python3 scripts/convert_texts.py
```

הסקריפט:

1. ממיר את כל קבצי הטקסט מ־CP1255 ל־UTF-8
2. ממפה את תו ה־`K` המיוחד ל־קמץ (`ָ`)
3. מרחיב כוללי `()` באופן רקורסיבי לדפי התפריט הראשי
4. כותב JSON תחת `data/`
