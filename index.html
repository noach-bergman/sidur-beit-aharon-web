      אודות

      אפליקציית אינטרנט (PWA) של סידור בית אהרן וישראל, מומרת מסידור Java ME (MIDlet) המקורי.

      נוסח התפילה נלקח מקבצי המשאבים של ה-JAR המקורי (קידוד Windows-1255), ללא המצאת נוסח. סדר התפריטים והעמודים תואם את Manager / MainMenu / Page.

      זמני היום מחושבים בקירוב (NOAA) לפי העיר שנבחרה — לא להלכה למעשה.
